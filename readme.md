Development has stopped in this repository, but the game continues under the name [Wilderstep: Infinite Abyss](https://github.com/mattjcamp/wilderstep_infinite_abyss) on Github.

I am still making the same game, but I decided to start over with the lessons I learned from the original attempt. The new version has a simpler data model and map editing system and writing the entire game in TypeScript and React has made the editor more managable.

So basically, Wilderstep is the next step for this project, reduces all the technical debt I built up from this game, and allows me to provide a web-first experience. You can still view the Realm of Shadow content and play the web version of the game if you want.

---

Realm of Shadow was my first attempt to vibe-code an RGP style game. It's an Ultima III  and D&D inspired top-down, turn-based RPG built with originally with Python and then with TypeScript and Phaser. It included a procedurally generated world of overworld exploration, town visits, dungeon delving, and tactical grid combat.

[You can try Realm of Shadow by clicking here to play online.](https://mattjcamp.github.io/game_rpg_turn_based_open_world/) 

### Features

- Dungeons & Dragons inspired turn-based combat system
- Quest system
- Procedurally generated dungeons and intentionally crafted adventures
- Race and class system
- [1980s-style Player's Manual](docs/manuals/players_guide.pdf), [Adventure Map](docs/manuals/overview_map.png), and [Cloth Map](docs/manuals/cloth_map.png)
- Game is saved to your browser's local storage
